When the container accumulator is low and the column isn't building pressure, a near-zero accumulator is also what a freshly started container looks like. Gather at least:
- container system_state (OFF / DEBUG / RUN)
- `co3ntrol_bop_sensors_co2_accumulator_dry_pressure{subsystem="container"}` trend (rising = starting; flat near zero = idle)
- container supervisor lock
- key BOP valves if ambiguous (purge_canal_valve, root_canal_valve)

Only call it "idle / not producing" if state is OFF or the accumulator has been flat near zero for several minutes. A fast rise after a brief startup is a normal transient; say so.

2026-07-15: 2.1 psi was called idle but was mid-startup; it reached 90 psi within ~2 min.
