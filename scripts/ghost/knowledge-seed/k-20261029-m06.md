- **airbed-host**: airbed system and the S3 hive host (bucket `provocative-dac-dev-beef`, `host=airbed-host`).

- Every host writes JSONL to `/var/log/co3ntrol/control-telemetry.log`, and Alloy scrapes `/metrics` (co3ntrol_* gauges) into Grafana Cloud Mimir. The hosts share one Grafana Cloud write token, so a token problem drops all of them at once.
