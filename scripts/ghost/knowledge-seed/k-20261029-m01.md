Datasource `grafanacloud-logs` (uid `grafanacloud-logs`). Check these for container state, purge failures, script errors and automation issues.

| `filename` label | Contents |
|---|---|
| `/var/log/co3ntrol/automation-console.log` | `container_system.py` output: filter cycles, purge events, failures, abort messages |
| `/var/log/co3ntrol/control-console.log` | co3ntrol-rs runtime log for the container node |
| `/var/log/co3ntrol/p1am-console.log` | PLC firmware console (liquefaction node) |
