- **V26 accumulator input valve**: solenoid on P1-16TR Y6 between prefilter and B4 dewpoint sensor; gates CO2 inlet to the accumulator. RUN forces OPEN; OFF/ERROR forced CLOSED; DEBUG via GUI `accumulator_input_valve` coil. Modbus ABI 12 (coil 9 / DI 17).
- **K7 prechiller**: spare relay repurposed; on in RUN like other chillers; GUI `prechiller_power`.
- **V25 dewpoint vent** upstream of the accumulator: E-02 wet dewpoint opens V25 instead of venting liquid product via V24.
- Liquid drain routing is O2-only (dewpoint removed from V7/V24 pulse logic).
- **E-03** (column pressure low warning) no longer forces column vent flow to 0 SLPM in RUNNING; the vent PID continues. Modbus ABI 11.
