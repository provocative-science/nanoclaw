Chillers only run when liquefaction is in RUN (or manually enabled in DEBUG); they are off when the system is off. Elevated coolant temps after an off period are expected, and going to RUN is how they recover. Never advise waiting for chiller temps to recover before restarting. Starting with chiller loops at room temperature is normal and safe. "Do not restart" only applies to a chiller hardware fault (refrigerant, compressor alarm, abnormal noise).
