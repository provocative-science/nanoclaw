# Global agent instructions

Shared instructions for all groups in this NanoClaw install.

Mounts: this file is available in containers as `/workspace/global/CLAUDE.md`.
Shared notes (when present) live under `/workspace/shared/`.

Plant-specific instructions live on the `instance/<name>` deploy branch
(not on `main`). Switch to that branch to edit Ghost/plant memory:

```bash
git switch instance/provocative
```

See [docs/INSTANCE-OVERLAY.md](../../docs/INSTANCE-OVERLAY.md).
